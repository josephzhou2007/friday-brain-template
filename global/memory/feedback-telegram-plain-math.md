---
name: Plain-text maths on Telegram
description: How to write maths in Telegram replies
metadata:
  type: feedback
---
Telegram does not render LaTeX. Write formulas as readable Unicode text or in a code block,
for example `x' = γ(x − vt)`.

**Why:** raw LaTeX like `\gamma(x - vt)` arrives as noise on a phone screen.

**How to apply:** every agent, every Telegram reply. Web pages and documents may use LaTeX.
